# GateFlow – samoobslužné odbavení řidičů (demo)

Statické interaktivní demo bez backendu a externích závislostí. Připravené pro Netlify.

## Čtyři obrazovky

1. Výběr jazyka (20 jazyků)
2. Příprava dokumentů a potvrzení
3. Simulovaný skener dokumentu
4. Výsledek – přidělená rampa 12

## Lokální spuštění

Otevřete `index.html` v prohlížeči.

## Nasazení na Netlify

Připojte tento GitHub repozitář jako zdroj existujícího Netlify projektu GateFlow Demo. Publikační adresář je kořen repozitáře (`.`), build není potřeba. Konfigurace je v `netlify.toml`.

## Upozornění

OCR, přiřazování rampy i připojení k WMS/YMS jsou pouze simulované. Demo nečte reálné dokumenty a neposílá osobní údaje do cloudu.
